How to Get Breakpoints to work with Intellij 2021.2.24 and Chrome 111
---------------------------------------------------------------------
Problem:  Chrome update to v111 stops breakpoints from working in the front-end
Fix #1:   Tell IntelliJ to start up Chrome with the --remote-allow-origins=*
Fix #2:   Downgrade to Chrome v110  (yeah, that's a crappy solution!!)



References
----------
https://intellij-support.jetbrains.com/hc/en-us/community/posts/10432962465682-unable-to-debug-javascript-in-2022-3-2-ultimate-edition-with-chrome-111-on-mac-m1-arm-?page=1#community_comment_10444522343570


Procedure #1
------------
 1. Startup IntelliJ

 2. Setup Chrome to run with the  --remote-allow-origins=*
    a. Pulls File -> Settings
    b. Selected Tools -> Web Browsers and Preview
    c. Select "Chrome" and press the "Edit" icon  (looks like a pencil)
    d. In the "Change settings" popup
       Command Line option:
           --remote-allow-origins=*

       Check "Use custom user data directory"
       NOTE:  This ensures that Chrome keeps overwriting the user data directory (instead of creating LOTS of new ones sucking up disk space)

    d. Press OK

 3. Try out the full debugger
    -- Chrome should startup and connect to localhost:4200
    -- Breakpoints should be working


Procedure #2 / If running on Windows make sure the registry RemoteDebuggingAllowed is enabled
---------------------------------------------------------------------------------------------
In 2026, I had a corporate-issued laptop that had a policy DISABLING the Chrome Remote Debugging
-- As a result, Intellij would launch Chrome with a remote debugging port (but it was not really debugging)
-- So, the intellij debugger kept saying, "Waiting for localhost:50250....Try another port"
-- And, front-end breakpoints did not work
-- Here is how I resolved it

Procedure
---------
 1. Create a special user data directory (in the non-standard place)
    NOTE:  You must specify a non-standard user data directory for remote debugging to work in Chrome
    Create this empty directory:  c:\tools\chrome-user-data\

 2. Enable Chrome Remote Debugging Windows Policy (by adjusting the registry)
    a. Open the registry editor as an administrator
    b. Go to HKEY_LOCAL_MACHINE \ SOFTWARE \ Policies \ Google \ Chrome \ RemoteDebuggingAllowed
	   -- Double-click on RemoteDebuggingAllowed
       -- Change it to 1  (hexadecimal value)

 3. In Intellij File, configure Chrome with certain command-line options
    a. Pull File -> Settings
    b. Click on Tools -> Web Browsers and Preview
    c. Click on Chrome -> Edit Icon

       Command Line Options:  --remote-allow-origins=*   --no-default-browser-check   --no-first-run
       Check "Use custom user data directory":    C:\tools\chrome-user-data


 Now, my front-end breakpoints worked on this Windows 11 laptop!!
