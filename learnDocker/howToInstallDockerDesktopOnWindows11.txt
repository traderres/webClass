How to Install Docker Desktop on Windows 11 (with kubernetes)
-------------------------------------------------------------

Assumptions
 A) You do not want to use WSL because it's prohibited
 B) You have windows admin access rights

Procedure
---------
 1. Uninstall any existing Docker Desktop (if already installed)
    Open Control Panel / Uninstall a program / Uninstalled Docker Desktop

 2. If you uninstalled, then reboot the computer

 3. Make sure "Hyper-V" and "Virtual Machine Platform" are installed
    a. Press Windows-R -> optionalfeatures.exe
    b. Make sure that "Hyper-V" [and its children] and "Virtual Machine Platform" are checked
    c. If not checked, then check them and press OK

 4. Download the Docker Desktop Installer
    a. Go to https://docs.docker.com/desktop/setup/install/windows-install/
    b. Select "Docker Desktop for Windows - x86_64"
    a. Save "Docker Desktop Installer.exe" to your Downloads directory

 6. Run the Docker Desktop Installer
    a. Go to Downloads
    b. Double click on "Docker Desktop Installer.exe"

 7. In the configuration
    Select:   All-user installation
    Uncheck:  "Use WSL2 instead of Hyper-V"
    Uncheck:  "Allow Windows containers"
    Check:    "Add shortcut to Desktop"
    Press "OK"

 8. Enter windows credentials
    -- You should see "Installation succeeded"

 9. Run the "Docker Desktop" shortcut on your desktop
    a. Press Settings icon (at the top)
    b. Under General
       Check   "Start Docker Desktop when you sign in to your computer"
       Uncheck "Open Docker Dashboard when Docker Desktop starts"

    b. Under Resources
       Adjust the memory to 16 GB
       Press "Apply"

    c. Under Kubernetes
       1) Press "Enable Kubernetes"

       2) Under Cluster Settings
          select "Kubeadm"      (Do NOT select kind)
          Press "Apply & Restart"
          Press "Install Kubernetes Cluster"

10. Wait a minute or two for Kubernetes to show "Running" Under the "Kubernetes" section

11. Verify kubernetes is running
    a. Open a terminal
       terminal> kubectl get services

       NAME         TYPE        CLUSTER-IP   EXTERNAL-IP   PORT(S)   AGE
       kubernetes   ClusterIP   10.96.0.1    <none>        443/TCP   2m7s

       -- This means we're happy!!!!
