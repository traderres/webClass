How to Install Postgres 17 on Windows
-------------------------------------


Procedure
---------
 1. Download the MSI installer
    a. Go to https://www.enterprisedb.com/downloads/postgres-postgresql-downloads

    b. Choose the Postgres installer for "Windows x86-64"
       Look For Postgres 17.10 / Windows x86-64



 2. Run the MSI installer
    a. Open your Downloads Directory
    b. Double-click on postgresql-17.10-2-windows-x64.exe
       NOTE:  It might install the Microsoft Visual C++ redistributables (that is fine)


      WARNING:  If you get this message:   "error occurred executing vc++ runtime", then follow these steps
        a. Open a terminal
        b. In the terminal, type-in these commands
           cd Downloads
           postgresql-17.10-2-windows-x64.exe --install_runtimes 0
                                                      ^
                                                      |
                               Add this command-line option to get the installer to run


   c. In the Setup page, press Next

   d. For the installation directory, go with the defaults
        C:\Program Files\PostgreSQL\17
      Press Next

   e. For the data directory, go with the defaults
        C:\Program Files\PostgreSQL\17\data
      Press Next

   f. For the password:
      password:  secret
      re-type:   secret
      Press Next

   g. For the port:
      Use the default 5432
      Press Next

   h. For Advanced Options,
      Locale:  Use English, United States
      Press Next

   i. In the Ready-to-install screen
      Press Next

   j. In the "Completing the postgresql setup wizard"
      Uncheck "Launch Stackbuilder at exit"
      Press Finish

      NOTE:  Scroll down to the BOTTOM to troubleshoot errors!!!!


 2. Verify that you have a Windows service for postgres
    a. <Start><Run>services.msc
    b. You should see a service named "postgresql-x64-17"


 3. Add psql to your PATH
    NOTE:  If installing postgres 17, then we want to add this to your PATH:
               C:\Program Files\PostgreSQL\17\bin

    a. In the windows search box, type-in environment
       Select "Edit Environment variables for YOUR account"

    b. Click on "Environment Variables"

    c. In the top part -- e.g., User variables for <YOUR WINDOWS USERNAME
       1) Double-click on Path
       2) Press "New" to add to the path
       3) Add this path:
             C:\Program Files\PostgreSQL\17\bin
        4) Press OK a few times

    d. Verify that the psql command works from the DOS window
       1) Open a DOS Window by pressing <Start><Run>CMD

       2) In the DOS window
          DOS> psql --version
          psql (PostgreSQL) 17.10


HELP #1:  I get the "Problem running the post-install step" error
-----------------------------------------------------------------
Problem:  I get this error message
		 "Problem running the post-install step, Installation may not complete correctly. The database cluster initialization failed"

Solution: Manually initialize the database *and*
          Manually create a windows service

Procedure
---------
 1. Initialize the database cluster
    a. Open a terminal  (NOT AS ADMINISTRATOR)

    b. Run these commands in this terminal
       cd "C:\Program Files\PostgreSQL\17\bin"
       initdb.exe -D "C:\PostgreSQL\data" -U postgres --locale=C --encoding=UTF8


 2. Register Postgres as a Windows Service
    a. Open a terminal as administrator

    b. Run these commands in this terminal
           cd "C:\Program Files\PostgreSQL\17\bin"
           pg_ctl.exe register -N "postgresql-x64-17" -D "C:\PostgreSQL\data"


 3. Reboot your laptop
    -- You created a service that will startup automatically
    -- but the postgres 17 service is *NOT* started yet
    -- Reboot your laptop to start it up


 4. After reboot, attempt to connect to your database
    a. Open a terminal (NOT AS ADMINISTRATOR)
    b. Run these commands
         psql -U postgres -h localhost

         select now();
         -- You should see the time



Help #2:  I get the "Warning: Console code page (437) differs from Windows code page (1252)"
---------------------------------------------------------------------------------------------
Problem:  When I run psql, I get this error "Warning: Console code page (437) differs from Windows code page (1252)"
Solution: Tell Windows to change the encoding of your terminal (to 1252) before running the psql command

Procedure
---------
 1. Verify that you see the error
    Open a terminal
      psql -U postgres -h localhost
      -- You will see the "Warning: Console code page (437) differs from Windows code page (1252)"

 2. Create this file:  psqlrc.conf
    Open a terminal (NOT AS ADMINISTRATOR)
    mkdir %appdata%\postgresql
    cd %appdata%\postgresl
    notepad psqlrc.conf
    -- When prompted to create a new file:  Press "yes"

 3. Put this in the file:
       \! chcp 1252

 4. Restart your laptop  (to restart Postgres)

 5. Verify that the warning is gone
    Open a terminal
      psql -U postgres -h localhost
      -- You will *NOT* see the "Warning: Console code page (437) differs from Windows code page (1252)"
