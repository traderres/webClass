How to Install Kabana 7.7.0 on Windows
--------------------------------------

Assumptions
-----------
 A) You already have ElasticSearch 7.7.0 installed on your Windows box
 B) You have a Java JDK installed
 C) You want to install Kibana 7.7.0




Procedure
---------
 1. Download Kibana 7.7.0
    a. Go to https://artifacts.elastic.co/downloads/kibana/kibana-7.7.0-windows-x86_64.zip
       NOTE:
          The main download page is here:
          https://www.elastic.co/downloads/past-releases/kibana-7-7-0

    b. Save it to your Downloads/ directory


 2. Install Kibana
    a. Right-click on kibana-7.7.0-windows-x86.zip -> 7zip -> Extract files...
       Extract To:  c:\tools
       -- Now, you should have these directories:
            C:\tools\kibana-7.7.0-windows-x86_64\bin\
            C:\tools\kibana-7.7.0-windows-x86_64\config\
            C:\tools\kibana-7.7.0-windows-x86_64\node\
            C:\tools\kibana-7.7.0-windows-x86_64\plugins\
            C:\tools\kibana-7.7.0-windows-x86_64\src\


 3. Configure kibana so that it has the correct ElasticSearch port
    NOTE:  I assume that your ElasticSearch is listening on port 9201
    a. Edit C:\tools\kibana-7.7.0-windows-x86_64\config\kibana.yml

    b. Change this line:
        #elasticsearch.hosts: ["http://localhost:9200"]

       To this:
         elasticsearch.hosts: ["http://localhost:9201"]

    c. Save your changes


 4. Startup Kibana manually
    a. Open a DOS window by pressing <Start><Run>CMD
       CMD> cd /d C:\tools\kibana-7.7.0-windows-x86_64\bin
       CMD> kibana.bat

       You should see this:
       {"name":"Kibana","hostname":"Ronda","pid":2340,"level":30,"msg":"No existing kibana index found","time":"2016-02-26T19:11:03.701Z","v":0}
       {"name":"Kibana","hostname":"Ronda","pid":2340,"level":30,"msg":"Listening on 0.0.0.0:5601","time":"2016-02-26T19:11:03.719Z","v":0}
         -- Now, kibana is listening on port 5601

	b. Verify it is running
	   1) Open a browser
	   2) Go to http://localhost:5601

    b. Now stop it by pressing Control-C


 5. Create a Windows Service to startup Kibana
    a. Download & Install the Non-Sucking Service Manager here https://nssm.cc
	   Clone the project
	      cd /d c:\tools
	      git clone https://github.com/imvickykumar999/Non-Sucking-Service-Manager.git nssm

	      -- When completed, you should have these directories:
		         C:\tools\nssm
				 C:\tools\nssm\src
				 C:\tools\nssm\win32
				 C:\tools\nssm\win64

	 b. Use nssm to create a Kibana Windows Service
	    1) Open a CMD window in **Administrative Mode**
		   by right-click on CMD -> Run as Administrator

		   CMD> cd C:\tools\nssm\win64
		   CMD> nssm install kibana

		2) In the nssm popup
		   Click In the Application tab
		       Path                 C:\tools\kibana-7.7.0-windows-x86_64\bin\kibana.bat
		       Startup Directory:   C:\tools\kibana-7.7.0-windows-x86_64\bin

		   Click in the Dependencies tab
		       elasticsearch-service-x64

		   Press "Install Service"


 6. Start your Kibana service using services.msc
    a. Run the Services app
    b. Look for kibana
    c. Right-click on kibana -> Start


 7. Configure your Windows Service to startup Kibana 7.7.0 on reboot
    a. Run the Services app
    b. Look for kibana
    c. Right-click on kibana 7.7.0 -> Properties
    d. Set the Startup Type = Automatic


 8. Verify it works on reboot
    a. Reboot your windows box
    b. Verify that both ElasticSearch is up on port 9201
       1) Open a browser
       2) go to http://localhost:9201
          -- You should see the ElasticSearch version info as 7.7.0

    c. Verify that Kibana is up on port 5601
       1) Open a browser
       2) Go to http://localhost:5601
          -- You should see the Kibana page
